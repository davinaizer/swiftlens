# SwiftLens Governance Index

## Purpose

This directory is the authoritative governance entrypoint for SwiftLens. Use the file that matches the decision you need to make.

## Read On Demand

- [PROJECT_RULES.md](PROJECT_RULES.md) - repo scope, canonical doc order, and out-of-phase rejection rules
- [ARCHITECTURE_GUARDRAILS.md](ARCHITECTURE_GUARDRAILS.md) - module boundaries, dependency direction, and forbidden coupling
- [CONTENT_GOVERNANCE.md](CONTENT_GOVERNANCE.md) - canonical document ownership, naming, and duplicate-removal rules
- [QUALITY_GATES.md](QUALITY_GATES.md) - merge and phase-closure gates
- [WORKFLOW_CONTRACT.md](WORKFLOW_CONTRACT.md) - phase-gated execution, TDD, and agent workflow contract
- [WORKFLOW_RULES.md](WORKFLOW_RULES.md) - operational workflow for planning, editing, and validation

## Rule

If a governance decision is not in the file you are reading, do not infer it from `AGENTS.md` or task chatter. Resolve it in the authoritative doc first.
